>MengBootanimation

About

Inspired by terminal.sexy, creating boot animations in Termux with a TUI (Text User Interface). Just pick your file, set the resolution and FPS, and hit convert! No more manual typing—way faster for all you modding enthusiasts.

Made with ❤️ by Juni.

Checkout the source code at Github

Installation Guide

1. Update repository

pkg update && pkg upgrade -y

2. Install Tools (fzf, ffmpeg, magick, zip)

pkg install python git fzf ffmpeg imagemagick zip -y

3. Izin Penyimpanan (Akses /sdcard)

termux-setup-storage

4. Install mkboot tools

curl -fsSL https://raw.githubusercontent.com/juns37/mkboot/main/setup.sh | bash

Usage

mkboot
